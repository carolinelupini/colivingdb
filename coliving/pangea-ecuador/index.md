## About

Pangea's three-week coworking chapter in Ecuador; the base city hasn't been announced yet. Accommodation not included — book separately (Pangea helps you find a place). The pass covers the community side: events and dinners, a local host and orientation, and a WhatsApp group. A coworking space isn't included either; Pangea points you to the best spots. It runs only if enough people sign up. Registration is on Luma, and the host approves each application. Disclosure: Caroline Lupini, who runs colivingDB, is part of the Pangea team.
